# 当当TV 官网首页 · DangDangTV Landing Page

面向 **当当TV（DangDangTV）** 的产品介绍首页，界面风格、柔和粗野主义（Neo-Brutalism）边框阴影与暗/亮双色主题参考 [hapi.run](https://hapi.run)。

## 特性

- **双色主题 & 中英切换**：默认深邃客厅暗色 + 青柠绿主色，一键切换暖米白亮色主题与中/英双语。
- **100% 真实运行截图**：内置海信电视（Android 11，Modern）实机截图与 Android TV 14 实跑截图，支持场景切换与全屏原图放大检视。
- **核心功能全景展示**：多维分类筛选、拼音首字母搜索、红果/速博双源独立短剧、电视频道数字选台与五大平台直播、手机扫码配源与本地加密 AI 找片。
- **原创奶牛猫“当当”矢量动画**：展示应用内同款轻量级多形态 SVG 动画。

## 本地运行与构建

```bash
npm install
npm run dev
npm run build
```
